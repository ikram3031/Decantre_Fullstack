### AB02: Fix Nodemailer Module Initialization Race & Validate Delivery Results
* **Date**: 2026-08-04
* **Impact**: Backend (SMTP email utilities & Members Controller error states)
* **Description**: Fixed an issue where the Nodemailer transport was instantiated before environment configuration variables were loaded, leading to `Missing credentials for "PLAIN"` authentication failures. Added dynamic lazy transport creation and enforced validation checks for `sendOtpEmail` results.
* **Changes**:
  * Implemented lazy initialization inside [`otpDelivery.js`](file:///e:/AAAAA/backend/src/utils/otpDelivery.js).
  * Replaced try-catch logs with active `emailResult.delivered` checks in [`MembersController.js`](file:///e:/AAAAA/backend/src/controllers/MembersController.js) (affecting `checkMemberEmail`, `loginMember`, `resendMemberOtp`, and `forgotPassword`).

### AB01: Add checkMemberEmail Endpoint for Member Verification Flow
* **Date**: 2026-08-04
* **Impact**: Backend (Members API Controller & Routes)
* **Description**: Added a new endpoint to query if a member's email exists and is verified. If the email is unverified (such as migrated WordPress users), it triggers a 6-digit OTP code creation and dispatches it via SMTP email.
* **Changes**:
  * Added `checkMemberEmail` function in [`MembersController.js`](file:///e:/AAAAA/backend/src/controllers/MembersController.js).
  * Registered `POST /api/v1/members/check-email` route in [`MembersRoute.js`](file:///e:/AAAAA/backend/src/routes/MembersRoute.js).
