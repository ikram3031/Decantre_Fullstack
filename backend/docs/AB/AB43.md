# [AB-43] Implement Natural Numeric Sorting for Attribute Values in Dashboard Controller

## Change Summary
- **Module**: Backend (`src/dashboard/controllers/attribute.controller.js`)
- **Impact**: Dashboard Attributes API (`GET /api/v1/dashboard/attributes`, `POST`, `PUT`)
- **Description**: Added natural numeric sorting (`Intl.Collator` with `{ numeric: true }`) for attribute values (e.g. "2 ml", "3 ml", "5 ml", "10 ml", "50 ml", "100 ml") in `getAttributes`, `createAttribute`, and `updateAttribute` handlers. This ensures attribute values are always returned and stored in correct ascending numeric order.

## Affected Files
- `backend/src/dashboard/controllers/attribute.controller.js`
- `backend/docs/AB/AB43.md`

## Business Impact
Eliminated out-of-order attribute value display in dashboard product variant presets and attribute management UI.
