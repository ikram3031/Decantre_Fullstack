🆘 COMMON ISSUES & SOLUTIONS

Issue: Port 27017 already in use
  Solution: lsof -i :27017
            Change MONGODB_PORT in .env
            or kill process: kill -9 <PID>

Issue: Port 8006 already in use
  Solution: lsof -i :8006
            Change TOYOLAND_FRONTEND_PORT in .env
            or kill process: kill -9 <PID>

Issue: MongoDB container won't start
  Solution: docker-compose -f docker-compose.toyoland.yml logs mongodb
            docker-compose -f docker-compose.toyoland.yml down -v
            docker-compose -f docker-compose.toyoland.yml up -d

Issue: Frontend container crashes
  Solution: docker-compose -f docker-compose.toyoland.yml logs toyoland-frontend
            docker-compose -f docker-compose.toyoland.yml build --no-cache toyoland-frontend
            docker-compose -f docker-compose.toyoland.yml restart toyoland-frontend

Issue: Out of disk space
  Solution: docker system df
            docker system prune -f
            docker volume prune -f

💡 PRO TIPS

Tip 1: Use Make Shortcuts
  Instead of long commands, use:
    make toyoland-mongo  → Quick MongoDB access
    make toyoland-logs   → View logs instantly
    make toyoland-help   → See all commands

Tip 2: Monitor in Background
  Terminal 1: docker-compose -f docker-compose.toyoland.yml logs -f
  Terminal 2: Do your work (logs appear in Terminal 1)

Tip 3: Backup Before Major Changes
  docker exec toyoland-mongodb-dev mongodump \
    -u admin -p 11223345 \
    --authenticationDatabase admin \
    --out /data/backups

Tip 4: Quick Reset If Stuck
  docker-compose -f docker-compose.toyoland.yml down -v
  docker-compose -f docker-compose.toyoland.yml up -d --build
