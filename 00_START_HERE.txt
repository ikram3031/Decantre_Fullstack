🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: Port already in use
  Solution: lsof -i :27017  (or :8006)
            Kill process or change port in .env

Problem: MongoDB won't start
  Solution: docker-compose -f docker-compose.toyoland.yml logs mongodb
            Reset: docker-compose -f docker-compose.toyoland.yml down -v

Problem: Frontend not responding
  Solution: docker-compose -f docker-compose.toyoland.yml logs toyoland-frontend
            Rebuild: docker-compose -f docker-compose.toyoland.yml build --no-cache

Problem: Out of disk space
  Solution: docker system prune -f
            docker volume prune -f
