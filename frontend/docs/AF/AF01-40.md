### AF03: Implement Step-wise Member Login Flow with OTP Verification
* **Date**: 2026-08-04
* **Impact**: Frontend (AuthModal component & API handlers)
* **Description**: Refactored the login layout to verify emails first before prompting for passwords. Handles migrated unverified users by entering the OTP verification and password reset screens.
* **Changes**:
  * Added `checkMemberEmail` API fetch helper in [`api.js`](file:///e:/AAAAA/frontend/src/lib/api.js).
  * Refactored [`AuthModal.jsx`](file:///e:/AAAAA/frontend/src/components/AuthModal.jsx) to add a `loginStep` state, conditionally rendering the password field only on step 2, adding back navigation, and integrating step-wise email verification.

### AF02: Fix Simple Products Details Page Blank Screen Crash
* **Date**: 2026-08-04
* **Impact**: Frontend (Product Details & More Products components)
* **Description**: Resolved a runtime crash (blank screen) on simple product details views due to empty swatches arrays and unhandled category objects calling `toLowerCase()`.
* **Changes**:
  * Secured `activeSwatch` to have a default value instead of `{}` in [`ProductDetail.jsx`](file:///e:/AAAAA/frontend/src/pages/ProductDetail.jsx).
  * Wrapped select size swatches rendering in checking condition to hide it for simple products.
  * Added safeguards inside [`MoreProducts.jsx`](file:///e:/AAAAA/frontend/src/components/sections/MoreProducts.jsx) to safely stringify category fields before casing.

### AF01: Fix Product 'Out of Stock' Rendering on Listing Pages
* **Date**: 2026-08-04
* **Impact**: Frontend (Shop, Catalog, Search Results, Season, Wishlist pages)
* **Description**: Fixed a UI bug where all variant products were displayed as "Sold Out" by default. The issue was caused by a hardcoded default selected size of `100ml` which did not exist on decant products.
* **Changes**:
  * Created [`getDefaultSelection`](file:///e:/AAAAA/frontend/src/store/productHelpers.js) in `productHelpers.js` to dynamically determine the size of the lowest price variation.
  * Replaced hardcoded `{ size: '100ml' }` fallback with the new dynamic helper in [`Shop.jsx`](file:///e:/AAAAA/frontend/src/pages/Shop.jsx), [`Catalog.jsx`](file:///e:/AAAAA/frontend/src/pages/Catalog.jsx), [`SearchResults.jsx`](file:///e:/AAAAA/frontend/src/pages/SearchResults.jsx), [`Season.jsx`](file:///e:/AAAAA/frontend/src/pages/Season.jsx), and [`Wishlist.jsx`](file:///e:/AAAAA/frontend/src/pages/Wishlist.jsx).
