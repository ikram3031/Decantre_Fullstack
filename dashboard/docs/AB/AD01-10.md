### AD02: Fix Dashboard Homepage Not Loading & ReactQueryProvider Missing

* **Date**: 2026-08-07
* **Impact**: Dashboard (`main.jsx`) — critical fix
* **Description**: The dashboard homepage was rendering a blank page after deployment because the root `App` component was never wrapped inside `ReactQueryProvider`. This provider is responsible for setting up `QueryClientProvider` (TanStack Query), `AuthProvider`, and the `Toaster`. Without it, no API calls could be made and no auth state was available, causing the entire UI to fail silently.
* **Changes**:
  - Modified [`main.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/main.jsx) to import `ReactQueryProvider` from `./components/providers.jsx` and wrap `<App />` inside it.

### AD01: Fix Dashboard Import Paths After Core/ Refactor & Live Deploy

* **Date**: 2026-08-07
* **Impact**: Dashboard (65 files across `src/`) — build fix & live deployment
* **Description**: The dashboard codebase was restructured: files were moved from `src/app/(core)/dashboard/` and `src/components/core/` to `src/pages/` and `src/components/` respectively. However, all import paths across the codebase still referenced the old `@/components/core/`, `@/hooks/core/`, `@/lib/core/`, and `@/utils/core/` aliases, causing a complete build failure with `UNLOADABLE_DEPENDENCY` errors. All import paths were updated systematically across 65 files. The `App.jsx` entry point was also updated to import from the new `@/pages/` locations. Build verified locally before pushing to the Live branch and deploying to VPS.
* **Changes**:
  - Modified [`App.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/App.jsx) to import from `@/pages/DashboardLayout` and `@/pages/DashboardPage`.
  - Updated all imports in `src/components/`, `src/hooks/`, `src/lib/`, `src/utils/`, and `src/pages/` (65 files total) to remove the `/core/` segment from paths.
  - Deployed to VPS via `docker compose -p live -f docker-compose.live.yml build --no-cache dashboard && up -d` — container `decantre-dashboard-live` started successfully on port `8015`.
  - Live URL: [https://v2.decantrebd.com](https://v2.decantrebd.com)
