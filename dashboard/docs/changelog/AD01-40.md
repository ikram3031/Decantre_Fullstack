### AD04: Dashboard Product Search API Endpoint & Meta Response Mapping Fix
* **Date**: 2026-08-06
* **Impact**: Dashboard (Products table, stock page, useProducts hook)
* **Description**: Fixed an issue where performing searches or filtering by category/brand in the dashboard caused product loading failures. The hook was sending search POST requests to the product creation route `/api/v1/products` instead of `/api/v1/products/search`. Additionally updated backend response metadata parsing to handle `total_products`, `total_pages`, and `current_page` snake_case fields.
* **Changes**:
  - Updated [`use-products.ts`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/hooks/core/use-products.ts) to point search POST requests to `/api/v1/products/search`.
  - Added support for backend metadata keys (`total_products`, `total_pages`, `current_page`).

### AD03: Variable Product Attribute Group Loading, Variation Image Uploads & Global Stock Management
* **Date**: 2026-08-05
* **Impact**: Dashboard (Product creation page) and Backend (Products, Images Controllers & Schemas)
* **Description**: Enabled batch-populating variants with pre-defined attributes ("Add All Presets" button). Moved stock tracking globally to the product level for all types (mandatory stock status, optional stock quantity) and removed stock inputs from variant rows. Deferred image uploads (both main and variants) to the final form submit to prevent orphaned server files. Created a date-based directory structure (YYMMDD) for uploads and renamed files using the product slug and variant labels. Added `imageUrl` support to the product variants schema on the backend.
* **Changes**:
  - Modified [`page.tsx`](file:///E:/AAAAA/dashboard/app/(core)/dashboard/products/new/page.tsx) to support deferred main and variant uploads, auto-populate group presets, expand form container width to `max-w-6xl`, and make stock management global.
  - Updated [`product.model.js`](file:///E:/AAAAA/backend/src/core/models/product.model.js) to support `imageUrl` in variants schema.
  - Modified [`ImagesController.js`](file:///E:/AAAAA/backend/src/core/controllers/ImagesController.js) to handle YYMMDD directory folders and custom slugified filenames.
  - Updated [`ProductsController.js`](file:///E:/AAAAA/backend/src/core/controllers/ProductsController.js) to parse and update `imageUrl` in variant arrays.
