### ND02: Fix Dashboard Tailwind CSS v4 Theme Inline and Missing ThemeProvider Context
* **Date**: 2026-08-08
* **Impact**: Dashboard (Styling, Dark Mode, Theme Context, Vite Build)
* **Description**: Resolved issues causing dashboard CSS styling to fail to render properly. Configured `@theme inline` in `src/index.css` so Tailwind CSS v4 dynamically evaluates color and theme variables defined in `:root` and `.dark`. Added `ThemeProvider` wrapper from `next-themes` inside `ReactQueryProvider` in `providers.jsx` so theme context and header theme toggle work properly. Reordered Vite plugins in `vite.config.js` to `[react(), tailwindcss()]`.
* **Changes**:
  * Updated `@theme` to `@theme inline` in [`index.css`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/index.css).
  * Wrapped `ThemeProvider` in [`providers.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/components/core/providers.jsx) and updated component syntax to arrow function.
  * Updated `ThemeProvider` in [`theme-provider.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/components/core/theme-provider.jsx) to arrow function syntax.
  * Adjusted plugin order in [`vite.config.js`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/vite.config.js).

### ND01: Restructure Dashboard to Standard React SPA Architecture with React Router
* **Date**: 2026-08-07
* **Impact**: Dashboard (Architecture, Routing, Layouts, Pages, File Naming)
* **Description**: Restructured the Vite-based dashboard application from a Next.js App Router style folder structure (`src/app/(core)/...`) to standard React SPA best practices (`src/pages/` and `src/layouts/`). Replaced manual page reloads and `window.location` routing with `react-router-dom` (`createBrowserRouter`, `RouterProvider`, `useNavigate`, `useLocation`, `<Link>`). Added `ReactQueryProvider` wrapper in `App.jsx` to resolve the uncaught auth context exception that was rendering a blank screen. Converted all page component filenames and imports to `camelCase`.
* **Changes**:
  * Moved and renamed layout component to [`dashboardLayout.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/layouts/dashboardLayout.jsx).
  * Reorganized pages under `src/pages/auth/`, `src/pages/dashboard/`, `src/pages/dashboard/products/`, `src/pages/dashboard/orders/`, and `src/pages/dashboard/billing/` with camelCase filenames.
  * Configured centralized router in [`router.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/router.jsx).
  * Configured `RouterProvider` and `ReactQueryProvider` in [`App.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/App.jsx).
  * Refactored navigation links in [`app-sidebar.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/components/core/dashboard/app-sidebar.jsx) to use `<Link>` and `useLocation`.
  * Updated redirect handling in [`auth-guard.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/components/core/auth-guard.jsx) and [`login.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/pages/auth/login.jsx) to use `useNavigate`.
