### ND01: Restructure Dashboard to Standard React SPA Architecture with React Router
* **Date**: 2026-08-07
* **Impact**: Dashboard (Architecture, Routing, Layouts, Pages, File Naming)
* **Description**: Restructured the Vite-based dashboard application from a Next.js App Router style folder structure (`src/app/(core)/...`) to standard React SPA best practices (`src/pages/` and `src/layouts/`). Replaced manual page reloads and `window.location` routing with `react-router-dom` (`createBrowserRouter`, `RouterProvider`, `useNavigate`, `useLocation`, `<Link>`). Added `ReactQueryProvider` wrapper in `App.jsx` to resolve the uncaught auth context exception that was rendering a blank screen. Converted all page component filenames and imports to `camelCase`.

  * Configured centralized router in [`router.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/router.jsx).
  * Configured `RouterProvider` and `ReactQueryProvider` in [`App.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/App.jsx).
  * Refactored navigation links in [`app-sidebar.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/components/core/dashboard/app-sidebar.jsx) to use `<Link>` and `useLocation`.
  * Updated redirect handling in [`auth-guard.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/components/core/auth-guard.jsx) and [`login.jsx`](file:///c:/Users/mdikr/Documents/CODE/Decantre_Fullstack/dashboard/src/pages/auth/login.jsx) to use `useNavigate`.
